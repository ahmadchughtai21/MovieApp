🎬 MadFlix API Documentation

RESTful API for Movies and TV Shows Data

Base URL: {{ request.build_absolute_uri }}/api/
Response Format: JSON
Authentication: Not required - All endpoints are public
CORS: Enabled for frontend development

🏠 Home & General

GET /api/ Try it
List all available API endpoints (JSON format)
GET /api/home/ Try it
Get all homepage data including trending movies/shows, popular content, etc.

🎬 Movies

GET /api/movies/ Try it
Get all movie categories (now playing, popular, upcoming)
GET /api/movies/trending/ Try it
?time_window=week (day|week)
Get trending movies
GET /api/movies/popular/ Try it
?page=1
Get popular movies with pagination
GET /api/movies/top-rated/ Try it
?page=1
Get top rated movies with pagination
GET /api/movies/upcoming/ Try it
?page=1
Get upcoming movies with pagination
GET /api/movies/now-playing/ Try it
?page=1
Get now playing movies with pagination
GET /api/movies/search/ Try it
?query=search_term&page=1
Search movies by title
GET /api/movies/{movie_id}/ Try it
Get detailed movie information, similar movies, credits, videos, and streaming URL
GET /api/movies/genre/ Try it
?genre_id=28&page=1
Get movies by genre ID (28=Action, 35=Comedy, 18=Drama, etc.)

📺 TV Shows

GET /api/shows/ Try it
Get all TV show categories (airing today, on air, popular, top rated)
GET /api/shows/trending/ Try it
?time_window=week (day|week)
Get trending TV shows
GET /api/shows/popular/ Try it
?page=1
Get popular TV shows with pagination
GET /api/shows/top-rated/ Try it
?page=1
Get top rated TV shows with pagination
GET /api/shows/airing-today/ Try it
?page=1
Get TV shows airing today with pagination
GET /api/shows/on-the-air/ Try it
?page=1
Get TV shows currently on the air with pagination
GET /api/shows/search/ Try it
?query=search_term&page=1
Search TV shows by title
GET /api/shows/{show_id}/ Try it
?season=1&episode=1
Get detailed show information, episodes, similar shows, navigation, and streaming URL
GET /api/shows/genre/ Try it
?genre_id=18&page=1
Get TV shows by genre ID
GET /api/shows/{show_id}/season/{season_number}/ Try it
Get detailed season information with all episodes
GET /api/shows/{show_id}/season/{season_number}/episode/{episode_number}/ Try it
Get detailed episode information

🏷️ Genres

GET /api/genres/ Try it
Get all genres for both movies and TV shows
GET /api/genres/movies/ Try it
Get all movie genres
GET /api/genres/shows/ Try it
Get all TV show genres

🔧 Utility

GET /api/search/ Try it
?query=search_term&page=1
Search across movies, TV shows, and people
GET /api/config/ Try it
Get TMDB configuration for image URLs and other settings
